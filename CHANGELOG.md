# Change Log

All notable changes to Markdown++ are documented in this file.

## 0.0.41

- Added `Ctrl/Cmd+B` for bold, `Ctrl/Cmd+I` for italic, and `Ctrl/Cmd+Shift+X` for strikethrough.
- Added theme-colored bold text and improved table-cell inline formatting.
- Added proportional spacing after headings.
- Added separate global and per-file Live Preview toggles.

## 0.0.40

- Renamed and branded the extension as Markdown++.
- Added Marketplace metadata, searchable Markdown-related keywords, and complete English feature documentation.
- Added the public `Markdown++: Toggle Live Preview` and `Markdown++: Toggle Image Paste Mode` commands.
- Added the `markdownplusplus.imagePasteMode` and `markdownplusplus.enableMarkdownWordWrap` settings.
- Added the `markdownplusplus.globalLivePreview` setting: Command Palette toggling is global, while the editor-title button remains per-file.
- Kept the assets-folder image workflow as the default and Base64 embedding as an optional mode.

## 0.0.39

- Preserved the right-hand table border inside horizontally scrollable tables.
- Made tables return to rendered mode when the cursor moves below them.

## 0.0.38

- Hardened editor message handling, image saving, and rendering error recovery.
- Improved cleanup and removed unused dependencies and development code.
- Preserved support for large clipboard images.

## 0.0.37 and earlier

- Built the continuous Obsidian-style Live Preview editing experience.
- Added granular Markdown source reveal, tables, task lists, nested structures, slash commands, theme integration, image workflows, and editor navigation.
